The short version

Does it collect anything about my child? No. There is no account, no sign-in, no name field, no email, no analytics, no advertising, and no cookie.
Does anything leave the device? No. Once the page has loaded, the games make no network requests at all. There is no server to send anything to.
What is stored, then? Settings (volume, motion, contrast) and the best run for each game, in this browser's local storage. It is shown in full further down this page.
Are there ads? No, of any kind, including our own.
Can my child spend money? No. There is no shop, no currency, no unlock that costs anything, and no payment code anywhere in the site.
Will it nag them to come back? No. There is no streak, no daily challenge, no countdown, and it never asks for permission to send a notification.
Does a session end? Yes, always. Each run has a fixed end, and when it ends the game stops and says so. It never starts the next one by itself.

What we claim, and what we refuse to claim

What is true: these games are designed around sustained attention, delayed reward and deliberate thinking. Each one asks for one kind of attention and is built so the difficulty comes from discriminating carefully rather than from reacting fast. That is a description of how they were made, and you can check it by playing one.

What we do not say: we do not say these games improve focus, increase attention span, train the brain, help with ADHD or any other condition, improve school or work performance, or produce any benefit that lasts once the game is closed. We have no evidence for any of that, so we make no such claim, and if you ever see this site say otherwise, that is a mistake and it should be reported as one.

This distinction is not lawyerly caution for its own sake. In January 2016 the US Federal Trade Commission settled with the maker of a well-known brain-training product over exactly these claims; the settlement required competent and reliable scientific evidence before any future claim about real-world benefit. We have none, so we make none.

How to check all of this yourself

  1. Open Harbor Watch, then open your browser's developer tools and select the Network tab.
  2. Clear the list, then play a whole run from start to finish.
  3. The list stays empty. Every file the game needs was loaded before the run began, and nothing is requested during play or after it.
  4. In the same developer tools, look under Application at Cookies: the list is empty, because this site sets none.

The project also records this automatically. A network capture taken during a full scripted run is committed in the repository at docs/network-capture.json, alongside the script that produced it, so the check can be repeated rather than believed.

What is deliberately missing

Some of these are real costs, and we would rather name them than let you discover them:

  • No progress across devices. Because there is no account, a run on the tablet is invisible on the laptop.
  • No leaderboards and no sharing. There is nowhere to compare a child against strangers, by design.
  • We cannot tell whether any of this works. Refusing analytics means we have no idea which game holds attention and which one is dull. We accept that.
  • Harbor Watch needs sight. The whole game is telling two shapes apart, so it cannot be played without vision. It can be played with one hand, with one key, with no sound, with no colour vision, and with every animation switched off.

Who made this

One person, with software agents doing the implementation under direction. The gameplay code was written by agents; the feel of the game — how heavy the barrier is, how long you get to decide — and every judgement about whether it is any fun belong to a human, and at the time of writing that human has not yet run a single playtest with anyone else. That is stated here because it is true, and because a page that asks you to verify its claims should start by verifying its own.
